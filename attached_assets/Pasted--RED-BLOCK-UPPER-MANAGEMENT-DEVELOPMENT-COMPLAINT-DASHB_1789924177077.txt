Active Complaint Logic
Show only developments with 1 or more active complaints.
Do not display developments with 0 active complaints.
Complaint totals should update automatically in real time.
When a complaint is corrected and closed, the count decreases.
When a development reaches 0 active complaints, it automatically disappears from the dashboard.

Purpose

This dashboard will give Upper Management a real-time view of every development and building with active complaints, allowing them to quickly identify trends, allocate resources, monitor performance, and track complaint reductions as violations and complaints are corrected and closed. It should display all developments with active complaints, organized in easy-to-read rows of 10, while automatically hiding any development that has no active complaints.
