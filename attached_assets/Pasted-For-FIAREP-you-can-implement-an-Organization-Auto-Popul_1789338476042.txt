For FIAREP, you can implement an Organization Auto-Populate Search feature. When a user selects or types an organization name such as NYCHA, all developments associated with that organization are automatically added to the client's property list.

Feature Flow
User enters organization name.
System searches Organizations database.
Matching organization is found.
All linked developments are retrieved.
Developments are automatically attached to the client profile.
User can remove individual developments if needed.
