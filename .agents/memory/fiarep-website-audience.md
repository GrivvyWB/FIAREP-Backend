---
name: FIAREP website audience
description: Defines the product boundary between FIAREP's management website and field-staff mobile app.
---

Preserve the existing FIAREP website theme, color scheme, layout, and branding when adding functionality. The website is primarily for Management and upper-management operations; regular field staff use the mobile app.

**Why:** The user explicitly wants mobile management capabilities available on the website without redesigning it or turning it into the regular field-worker interface.

**How to apply:** Add shared oversight, review, routing, assignment, approval, alert, and administrative functions to web. Keep field-worker execution flows app-first unless management needs the same function for oversight or intervention.
